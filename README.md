# Consecutive Repeated Words Counter

A simple C++ program that detects consecutive repeated words in an input stream.

## Features

- Detects consecutive repeated words.
- Counts the total number of consecutive repetitions.
- Counts repetitions for each repeated word.

## Requirements

- A C++ compiler, such as `g++`.

## Compile

```bash
g++ RepeatedWords.cpp -o Source
```

## Run

To read input from `salam.txt` and save the output to `output.txt`:

```bash
./Source < salam.txt > output.txt
```

To display the output in the terminal instead:

```bash
./Source < salam.txt
```
